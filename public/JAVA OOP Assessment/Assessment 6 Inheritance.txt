B. A mechanism where a class acquires the properties and behaviors (fields and methods) of another class

C. extends 
D. super

A. Superclass 
B. Base class 
C. Parent class 
D. Subclass (or child/derived class)

A. It makes variables private automatically 
B. It promotes code reusability by allowing subclasses to reuse fields and methods from the superclass 
C. It prevents classes from having constructors 
D. It removes the need for objects

A. class Dog implements Animal { } 
B. class Dog extends Animal { }

B. No, Java only allows a class to extend one superclass directly

A. this 
B. super 
C. base 
D. parent

A. Creating two methods with the same name but different parameters 
B. When a subclass provides its own specific implementation of a method already defined in its superclass

A. Only the method name 
B. The method name, return type, and parameter list

A. To delete the superclass's constructor 
B. To call and execute the superclass's constructor, so its initialization logic runs before the subclass's own

A. It causes a compile-time error always 
B. Java automatically calls the superclass's no-argument constructor first

B. An 'is-a' relationship (e.g., a Dog IS-A Animal)

A. System

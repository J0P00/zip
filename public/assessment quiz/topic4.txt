Topic 4: Encapsulation in Java OOP

Question Bank (Questions 1–25)

1. What is encapsulation in Java?

A. Combining data and methods into a single unit while restricting direct access to data

B. Creating multiple objects from one class

C. Writing several methods with the same name

D. Creating abstract classes

Answer: A

2. Which access modifier is commonly used to achieve encapsulation?

A. public

B. protected

C. private

D. static

Answer: C

3. Why are instance variables often declared as private?

A. To make them accessible from anywhere

B. To hide data and prevent unauthorized access

C. To improve program speed

D. To allow inheritance

Topic 2: Constructors in Java OOP

Question Bank (Questions 1–25)

1. What is the primary purpose of a constructor in Java?

A. To delete an object

B. To initialize an object when it is created

C. To define a method

D. To terminate a program

Answer: B

2. What is a constructor?

A. A special variable

B. A special method used to initialize objects

C. A package

D. A Java keyword

Answer: B

3. Which statement about constructors is TRUE?

A. Constructors have a return type.

B. Constructors must return an object.

C. Constructors have the same name as the class.

D. Constructors can only be private.

Answer: C

4. Which of the following is the correct constructor declaration?
class Student{
    __________
}

A.

void Student(){}

B.

Student(){}

C.

constructor Student(){}

D.

new Student(){}

Answer: B

5. Which statement automatically calls a constructor?

A.

Student();

B.

Student s;

C.

Student s = new Student();

D.

new();

Answer: C

6. What happens if no constructor is defined in a class?

A. Java automatically creates a default constructor.

B. The class cannot be instantiated.

C. A syntax error occurs.

D. The object cannot store values.

Answer: A

7. Which constructor has no parameters?

A. Parameterized Constructor

B. Default Constructor

C. Static Constructor

D. Abstract Constructor

Answer: B

8. Which constructor accepts arguments?

A. Default Constructor

B. Empty Constructor

C. Parameterized Constructor

D. Static Constructor

Answer: C

A. A constructor initializes objects.

B. A constructor has the same name as its class.

Topic 6: Inheritance | extends | super in Java OOP

Question Bank (Questions 1–25)

1. What is inheritance in Java?

A. A way to create multiple constructors

B. A mechanism that allows one class to acquire the properties and methods of another class

C. A method for hiding data

D. A way to overload methods

Answer: B

2. Which keyword is used to inherit a class in Java?

A. inherit

B. implements

C. extends

D. super

Answer: C

3. In inheritance, the class being inherited is called the:

A. Child Class

B. Derived Class

C. Parent (Superclass)

D. Object Class

Answer: C

4. The class that inherits from another class is called the:

A. Parent Class

B. Child (Subclass)

C. Main Class

D. Static Class

Answer: B

5. Which of the following correctly creates an inheritance relationship?

A.

class Dog inherits Animal { }

B.

class Dog extends Animal { }

C.

class Dog implements Animal { }

D.

class Dog super Animal { }

Answer: B

6. What is the primary benefit of inheritance?

A. Faster compilation

B. Code reusability

C. Smaller variables

D. Automatic object creation

Answer: B

7. Which keyword refers to members of the parent class?

A. this

B. parent

C. super

D. extends

Answer: C

8. What is the purpose of the super keyword?

A. Create a new object

B. Access members of the parent class

C. Declare a class

D. Hide variables

Answer: B

A. Java supports single inheritance for classes.

B. A subclass can access public members of its superclass.

A. Multiple Inheritance

B. Single Inheritance

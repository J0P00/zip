Topic 11: Enum in Java OOP

Question Bank (Questions 1–25)

1. What is an enum in Java?

A. A class used for inheritance

B. A special data type used to define a fixed set of constants

C. A constructor

D. A method

Answer: B

2. Which keyword is used to declare an enum?

A. class

B. interface

C. enum

D. final

Answer: C

3. Which of the following correctly declares an enum?

A.

enum Day {
    MONDAY, TUESDAY, WEDNESDAY
}

B.

class Day {
    MONDAY, TUESDAY
}

C.

Enum Day {
}

D.

constant Day {
}

Answer: A

4. Which statement is TRUE about enum constants?

A. They can change at runtime.

B. They are fixed and predefined.

C. They must be integers.

D. They are methods.

Answer: B

5. Which enum declaration is valid?

A.

enum Color{
    RED, GREEN, BLUE
}

B.

enum Color{
    RED GREEN BLUE
}

C.

Color enum{
}

D.

class enum Color{
}

Answer: A

6. What does the values() method return?

A. A single enum constant

B. An array containing all enum constants

C. A String

D. An integer

Answer: B

7. What does the valueOf() method do?

A. Returns all enum values

B. Converts a String to its corresponding enum constant

C. Returns the index of an enum constant

D. Creates a new enum

Answer: B

8. What does the ordinal() method return?

A. The name of the enum constant

B. The index position of the enum constant

C. The total number of constants

D. A boolean value

Answer: B

9. Consider the following enum:
enum Day{
    MONDAY,
    TUESDAY,
    WEDNESDAY
}

What is the result of:

System.out.println(Day.MONDAY.ordinal());

A. 1

B. 0

C. MONDAY

D. Error

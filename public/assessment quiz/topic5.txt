Topic 5: Constructor Overloading in Java OOP

Question Bank (Questions 1–25)

1. What is constructor overloading in Java?

A. Creating multiple classes with the same name

B. Creating multiple constructors with different parameter lists in the same class

C. Creating multiple methods with different return types only

D. Creating multiple objects using one constructor

Answer: B

2. Which statement is TRUE about overloaded constructors?

A. They must have different names.

B. They must have different parameter lists.

C. They must have different return types.

D. They must be declared as static.

Answer: B

3. Which of the following is a valid example of constructor overloading?

Student(){}
Student(){}

C.

Student(){}

D.

Student(int id){}

4. Why is constructor overloading useful?

A. It allows objects to be initialized in different ways.

B. It makes all variables public.

C. It prevents object creation.

D. It replaces inheritance.

5. Which constructor is called?

Topic 7: Polymorphism in Java OOP

Question Bank (Questions 1–25)

1. What is polymorphism in Java?

A. The ability of one object to take many forms

B. The process of hiding data

C. Creating multiple constructors

D. Declaring private variables

Answer: A

2. Which OOP principle allows one interface to have multiple implementations?

A. Encapsulation

B. Inheritance

C. Polymorphism

D. Abstraction

Answer: C

3. Runtime polymorphism in Java is achieved through:

A. Constructor Overloading

B. Method Overloading

C. Method Overriding

D. Interfaces only

Answer: C

4. Which keyword is commonly used when overriding a method?

A. @Override

B. @Inherited

C. @Method

D. @Polymorphism

Answer: A

5. What is method overriding?

A. Defining multiple methods with the same name in one class

B. Redefining a parent class method in the child class

C. Calling multiple methods at once

D. Creating multiple constructors

Answer: B

6. Which statement correctly demonstrates polymorphism?
Animal animal = new Dog();

A. It creates two objects.

B. A parent reference refers to a child object.

C. It creates an interface.

D. It is invalid Java syntax.

Answer: B

7. Which method is executed during runtime?
Animal animal = new Dog();
animal.sound();

A. The parent's sound() method

B. The child's overridden sound() method

C. Both methods

D. No method

Answer: B

    }

    }
}

public class Main{
    public static void main(String[] args){
        Animal a = new Dog();
        a.sound();
    }
}

Animal Sound

B.

Dog Barks

C.

Animal
Dog

D. Error

10. Which statement is TRUE about polymorphism?

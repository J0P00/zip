Topic 10: Array of Objects in Java OOP

Question Bank (Questions 1–25)

1. What is an array of objects in Java?

A. An array that stores primitive data types only

B. An array that stores references to objects

C. A method that stores objects

D. A constructor that creates arrays

Answer: B

2. Which statement correctly declares an array of Student objects?

A.

Student student;

B.

Student[] students;

C.

Student students;

D.

Array<Student> students;

Answer: B

A.

B.

Student[] students = new Student[5];

C.

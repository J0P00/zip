Topic 9: Abstraction (Interfaces) in Java OOP

Question Bank (Questions 1–25)

1. What is an interface in Java?

A. A special class used to create objects directly

B. A blueprint that defines methods a class must implement

C. A constructor with multiple parameters

D. A package in Java

Answer: B

2. Which keyword is used to declare an interface?

A. abstract

B. class

C. interface

D. implements

Answer: C

3. Which keyword is used by a class to use an interface?

A. extends

B. implements

C. inherits

D. super

Answer: B

}

}

D.

}
